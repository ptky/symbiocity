# SymbioCity

A jövő lakónegyede: egy képzeletbeli fenntartható okosváros terve.

**Bemutató:** https://ptky.github.io/symbiocity/

10 dia, körülbelül 6 perc 45 másodperc. Lapozás nyilakkal, F a vetítési módhoz, Escape a kilépéshez. A G billentyű a diajegyzéket nyitja meg.

A weboldal a vetített tartalmat és az új generált koncepcióképeket tartalmazza. Az előadói szövegek külön Word-fájlban maradnak. A költségkeret fiktív.

Offline is működik az index.html megnyitásával, ha az assets mappa és a többi webes fájl mellette marad.
